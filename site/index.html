Git for agent swarms.
One server for every agent.

TreeYard is a self-hosted version control server for 10 to 200 AI coding agents on one repository. Agents get a workspace in about a second, see each other's edits while they work, and land in milliseconds. Git stays the source of truth. Apache-2.0, one binary.

What hurts with git worktrees

  1. Conflicts show up too late. 27.67% of 107K+ agent pull requests have a merge conflict (arXiv 2604.03551, a preprint).
  2. Work gets lost. Worktree cleanup and one agent's git stash delete another's work (Claude Code issues #46444, #102465).
  3. Every agent sets up a full checkout. Builds and dependencies again, per agent.
  4. Landing is serial. With each repo's own CI, the 50th change waits 248 s (ripgrep) to 3 614 s (requests).

How it works

Changes, not branches
An agent opens a change (one row), applies edits, and lands. Stable ids; every revision kept.
Conflicts as tasks
The server rebases and merges on land. A conflict returns base, ours, theirs and who changed the path.
Live collisions
Every apply lands each pair of open changes on today's main, both orders, and says why they would conflict. Intents and events warn before land.
Copy-on-write workspaces
A clone of a built base, with target/ or node_modules as a layer. Synced to the change after each edit.
Git underneath
Each land is one deterministic git commit. People clone, pull and push; mirror to GitHub.
One API, three doors
HTTP, MCP (Claude Code, Codex, OpenCode) and the CLI share one operation table.

Start

treeyard init --data rs-data --from ./my-repo
treeyard serve --data rs-data &
claude mcp add --transport stdio treeyard -- treeyard mcp --agent claude-1

Full steps, checked word for word in an empty directory on macOS and Linux: docs/quickstart.md. Agents: docs/mcp.md. Versus worktrees, GitButler, jj and merge queues: docs/comparison.md.

Honest limits

  • Land times do not include CI. Use the queue or optimistic landing mode to test.
  • Conflict warnings catch 100 % of real conflicts; 72 % to 85 % of warnings really conflict.
  • v0.1 is one node. No TLS and no token expiry yet.
  • Every agent in these numbers is a script. No Claude Code, Codex or OpenCode session ran.
