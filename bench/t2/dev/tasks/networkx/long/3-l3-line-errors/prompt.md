# Text formats: errors that say which line

When the parsers of the edge list, adjacency list, multiline adjacency list, Pajek and LEDA formats (`parse_edgelist`, `parse_adjlist`, `parse_multiline_adjlist`, `parse_pajek` and `parse_leda` in `networkx/readwrite/edgelist.py`, `adjlist.py`, `multiline_adjlist.py`, `pajek.py` and `leda.py`) cannot read a line, they raise an error that does not say which line, and the `read_*` functions do not say which file. Add an exception for this.

- `networkx.LineParseError(message, lineno, line, filename=None)` in `networkx/exception.py` (listed in its `__all__`, so it is `nx.LineParseError`): a subclass of `NetworkXError` and of `TypeError`, so code that catches either keeps working. Its attributes are `message`, `lineno`, `line` (the text of the line without its line end) and `filename`. `str()` of it is `line <lineno>: <message>`, or `<filename>:<lineno>: <message>` when `filename` is set (it may be set after the error is made).
- `lineno` counts every line given to the parser, from 1, comment and blank lines included (for a string given to `parse_pajek` or `parse_leda`, the lines are its parts between `\n`).
- Edge list, adjacency list, multiline adjacency list: every `TypeError` that the three parse functions raise today about their input (a node, edge data or degree that does not convert, a multiline adjacency list that ends before all neighbours of a node) is a `LineParseError` instead, with today's text as its `message` and the original error as its `__cause__`. For the missing neighbours of a multiline adjacency list the line is the line of the node. The `IndexError` about the number of data keys stays as it is.
- Pajek: a `*vertices` line whose count is not an integer (that line); fewer vertex lines than that count (the `*vertices` line); a vertex line that cannot be split (a quote that is not closed) or has fewer than two fields (that line); an edge or arc line that cannot be split (that line); a `*matrix` entry that is not an integer (its line).
- LEDA: a graph type, number of nodes or number of edges that is not an integer (that line); a file that ends before all nodes or edges are read (`lineno` is one more than the last line given, `line` is `""`); an edge line with too few fields or with a node number that is not a node (that line).
- `read_edgelist`, `read_weighted_edgelist`, `read_adjlist`, `read_multiline_adjlist`, `read_pajek` and `read_leda` set `filename` of the error to the name of the file they read (the `name` of the file object, which is the path for a path or file name; `None` for a file object without a name) before it reaches the caller: `graph.txt:3: Failed to convert nodes x,3 to type <class 'int'>.`

Document the exception in the module docstring of each of the five modules.

Keep the existing behaviour otherwise. Finish the work completely.
