# Line formats: node names with spaces

The edge list, adjacency list and multiline adjacency list formats (`networkx/readwrite/edgelist.py`, `networkx/readwrite/adjlist.py` and `networkx/readwrite/multiline_adjlist.py`) write a node as `str(node)` and split every line at the delimiter, so a node named `New York` is written as two words and read back as two nodes. Add quoting to all three formats, in their `generate_*`, `write_*`, `parse_*` and `read_*` functions.

- Writing: a node name (`str(node)`) is written in double quotes when it is empty, or contains any whitespace character, the delimiter of the call, `#`, a double quote or a backslash. Inside the quotes a backslash is written as `\\`, a double quote as `\"`, a line feed as `\n` and a carriage return as `\r` (so a name never breaks a line). Every other name is written as today (`plain`, `é-1`).
- Edge data is written as today, with one exception: with a list of data keys (`generate_edgelist(G, data=["label"])`, `write_edgelist(..., data=["label"])`) a value that is a `str` is quoted by the same rule: `1 2 "dark red" 3`. With `data=True` or `data=False` nothing changes.
- `write_adjlist` and `write_multiline_adjlist` write the name of the graph on their third comment line (`# <name>`). A name that needs quotes by the rule is written quoted there (`# "x\ny"`), so the comment stays one line; other names as today.
- Reading: where a line holds a node name (both names of an edge list line, every token of an adjacency list line, the name at the start of each line of a multiline adjacency list), a token that starts with `"` is a quoted name. It runs to the next `"` that is not escaped; `\\`, `\"`, `\n` and `\r` inside it stand for a backslash, a double quote, a line feed and a carriage return, and the name is the text between the quotes (`""` is the empty name). A delimiter or the comments string inside the quotes is part of the name, not a split or a comment. A quote that is not closed raises `TypeError`. Tokens are separated by the delimiter, or by runs of whitespace when it is `None`, as today. The rest of an edge list or multiline line after the names is the edge data, read as today; with a list of data keys (`data=(("label", str), ("weight", int))`) every data value may be quoted too and is read as one value (`1 2 "dark red" 3` gives `label="dark red"`, `weight=3`).
- So a graph with string nodes round-trips: `read_x(write_x(G))` has the nodes and edges of `G`.

Document the quoting in the module docstring of each of the three modules and in the docstrings of the writers and readers.
